# HelpKoro Documentation

This repository contains the source-of-truth documentation for HelpKoro, a Bangladesh-first fundraising and crowdfunding SaaS. Product, engineering, and operational decisions are specified in `docs/`; implementation must follow `CLAUDE.md`.

## Documentation map

Start with `docs/00-foundations/product-vision.md`, then read the relevant domain section. Bangladesh payment, tax, charity, identity, data-protection, and fundraising rules are deliberately labelled **Validate** until approved by qualified local counsel and the chosen providers.

## Status

The documentation is implementation-ready but not legal or regulatory advice. Update a decision record whenever a material assumption changes.
