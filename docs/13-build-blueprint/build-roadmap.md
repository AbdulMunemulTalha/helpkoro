# Build Roadmap

## Phase 0: Platform

Create monorepo, Docker, CI, configuration/secrets contract, database migrations, shared UI, API shell, auth/RBAC, audit events, and telemetry. Exit: all local and CI commands pass.

## Phase 1: Campaigns

Build profiles, organizer onboarding, campaign drafts, uploads, submission, public campaigns, discovery, reports, organizer dashboard, and reviewer queue. Start with manual review and seeded data.

## Phase 2: Donations and ledger

Build provider adapter interface, sandbox checkout, signature-verified webhook processing, immutable ledger, receipts, donor history, reconciliation import, and refund simulation. Exit: financial failure matrix passes.

## Phase 3: Payout and operations

Build payout eligibility, dual approval, sandbox payout adapter, holds, finance console, support workflows, notifications, and incident/report operation.

## Phase 4: Launch hardening

Complete accessibility, localization, security/load testing, backup-restore drill, operational training, provider acceptance, monitoring, and all Bangladesh legal/provider Validate approvals. Do not process real funds before written launch sign-off.
