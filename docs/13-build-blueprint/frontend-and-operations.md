# Frontend and Operations Applications

## Public web

Build home/discovery, search, campaign detail, updates, donation checkout, payment-return state, receipt, authentication, organizer onboarding, campaign wizard, organizer dashboard, donor history, account settings, help, report, policy, and status pages.

## Operations web

Create separately protected review queue and case pages, reports queue, campaign controls, private evidence viewer, payout queue and dual approval, reconciliation dashboard, refunds/disputes, support account timeline, user/campaign audit view, feature flags, and read-only ledger lookup.

## UX rules

Use mobile-first responsive layouts, Bangla/English content keys, semantic accessible components, clear fee and status disclosure, and loading/error/empty/slow-network states. Never include private evidence or payout fields in public pages, source maps, screenshots, or URLs. End-to-end tests cover critical donor, organizer, reviewer, and finance flows.
